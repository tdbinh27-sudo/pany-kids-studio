🧪 Thử thay đổi (mở Notepad):

Đổi setGravity(2400) → setGravity(600) → nhân vật rơi chậm như trên mặt trăng 🌙

Đổi loop(2, ...) → loop(0.5, ...) → 🍎 rơi nhanh gấp 4 lần

Đổi màu color(255, 107, 107) → color(0, 255, 0) → nhân vật xanh lá
