# 👗 Pany Kids Fashion Design Track

**Mục tiêu:** Cho 3 con (Phúc 11t · An 9t · Y 5t) khám phá nghề **Fashion Designer / Illustrator / UI-UX Designer / Costume Designer** thông qua việc tự tạo nhân vật + thiết kế trang phục + đặt vào môi trường (nhà/xe/công viên/trường...).

**Stack OSS:** Open Peeps (CC0 public domain) + DiceBear (MIT 8.7K⭐) + Avataaars (MIT 3K⭐) + Figma free.

---

## 3-tier track theo tuổi

### 👶 Tier 1 — Y 5t · Khám phá nhân vật ngẫu nhiên

**Tool:** [DiceBear Playground](https://www.dicebear.com/playground/)
**License:** MIT (8.7K⭐)
**Install:** Không cần — chạy 100% browser

**Bố hướng dẫn (10-15 phút/buổi):**
1. Mở https://www.dicebear.com/playground/
2. Chọn style **"Open Peeps"** (cartoon hand-drawn, kid-safe)
3. Bấm nút "Randomize" 5-10 lần
4. Y chọn 1 nhân vật con thích
5. Bấm "Download" → PNG → save vào Portfolio tab

**Bố hỏi Y:**
- "Nhân vật này giống ai? (mẹ? An? bạn?)"
- "Con muốn nhân vật mặc gì?"
- "Cho nhân vật tên gì?"

**Output:** 5 nhân vật/tháng → Y kể chuyện 5 bạn này → journal entry.

📌 Chi tiết: `tier1-dicebear-guide.md`

---

### 🧒 Tier 2 — An 9t · Thiết kế trang phục chi tiết

**Tool:** [Avataaars Generator](https://getavataaars.com/)
**License:** MIT (3K⭐)
**Install:** Không cần — chạy 100% browser, output SVG

**An tự làm (30 phút/buổi):**
1. Mở https://getavataaars.com/
2. Customize từng phần:
   - **Top** (tóc/mũ): 30+ options (short hair, hijab, hat, bun...)
   - **Accessories** (kính): round, prescription, sunglasses...
   - **Hair color**: 6 màu
   - **Facial hair**: beard light/medium/magnum, mustache
   - **Clothes**: blazer, hoodie, overall, shirt, sweater, t-shirt
   - **Clothes color**: 10+ màu
   - **Eyes / Eyebrow / Mouth**: 8-12 options
   - **Skin tone**: 7 shades
3. Download SVG → save vào Portfolio
4. **Project:** Thiết kế 5 nhân vật family (Bố · Mẹ · Phúc · An · Y) → 1 PNG composite

**Bố hỏi An:**
- "Tại sao con chọn outfit này cho bố?"
- "Outfit thay đổi theo mùa thế nào?"
- "Một ngày con thiết kế outfit gì cho Y đi học?"

**Output:** Portfolio 20+ avatars/3 tháng → An biết khái niệm color palette + style match.

📌 Chi tiết: `tier2-avataaars-guide.md`

### 👨‍🎨 Tier 3 — Phúc 11t · Cảnh nhân vật trong môi trường

**Tools:**
- **Open Peeps** (CC0 public domain, 584,688 combinations) — https://www.openpeeps.com/
- **Figma free** (10-edit per file free tier) — https://www.figma.com/
- **PANY scene backdrops** (8 scenes anh-curated, CC0)

**Phúc tự làm (1-2h/project):**
1. Tải Open Peeps `.fig` file (đã CC0) hoặc download PNG/SVG individual
2. Mở Figma free → "New design file"
3. Drag scene backdrop SVG vào canvas (nhà/xe/công viên/...)
4. Drag nhân vật Open Peeps lên scene
5. Compose: 1-3 nhân vật + 1 scene + text bubble (optional)
6. Export PNG @2x → save vào Portfolio
7. (Optional) Print A4 → treo phòng

**Projects gợi ý:**
- **Project 1:** "Family ở công viên" — 5 nhân vật family + scene park
- **Project 2:** "Y ở trường" — Y + 3 bạn + scene classroom
- **Project 3:** "An đi cafe với mẹ" — An + mẹ + scene café
- **Project 4:** "Bố đi làm" — Bố + xe + scene office building
- **Project 5:** "Phúc tương lai 20 tuổi" — Phúc adult + nghề Phúc muốn làm + scene tương ứng

**Bố hỏi Phúc:**
- "Mỗi nhân vật trong scene đang nghĩ gì?"
- "Outfit có phù hợp với scene không? Tại sao?"
- "Nếu thay scene khác, outfit có cần đổi không?"

**Output:** 5 scene completed/quarter → portfolio đủ submit Behance/Dribbble tài khoản free (Phúc tự setup khi 13t+).

📌 Chi tiết: `tier3-figma-scene-guide.md`
